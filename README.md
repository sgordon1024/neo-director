# Neo Director

An offline-first cinematography assistant prototype. Typed requests become proposed shots and simulated timelines. No drone connection, speech model, or vision model is running.

[Progress tracker](https://sgordon1024.github.io/neo-director/)

The intended system connects iPhone headphones to local speech, vision and planning on a Mini that stays in the van. Local radio range limits trail use. This is separate from cloud ChatGPT; cloud voice is not promised offline.

DJI Neo 2 SDK support is not established. Experimental third-party control is not production readiness. No flight or motor operations are authorized by this project.

See [architecture](docs/ARCHITECTURE.md), [safety](docs/SAFETY.md), and [roadmap](docs/ROADMAP.md).
