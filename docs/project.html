THE PROJECT / CONTEXT & EVIDENCE

Designed for
the way out there.

Headphones and an iPhone, with local speech, vision and planning on a Mini in the van. Today: a working typed simulator.

What is real today

The browser prototype uses a strict typed grammar, immutable shot proposals and an independent safety supervisor. It runs offline after caching. No speech model, vision model, live GPS or drone connection runs in the browser.

Native media groundwork

A separate local tool writes spoken proposal files and measures image/video-frame pixel statistics. This is not speech recognition or scene understanding. Transcription model availability and OCR remain unresolved. Read the native test evidence ↗

The intended architecture

Headphones ↔ iPhone ↔ local Mini services → proposed shot → independent safety supervisor → separately gated Linux bridge. The Mini stays in the van, so radio range limits trail use. This is separate from cloud ChatGPT; cloud voice is not promised offline.

Evidence, not estimates

Stages have explicit completed, in-progress, blocked or planned states. Colors distinguish workstreams. There are no invented progress percentages or promised flight dates.

The flight gate stays closed.

Landing, physical/manual takeover, stale telemetry and lost-link behavior must be independently proven. Recognition is not obstacle avoidance. Vehicle tracking requires a separate pilot.
